# Persona Studio

An Orca plugin where personas use your app and report what gets in their way (run them from the sidebar, then Discuss a finding or Start work on it). You triage what they find, have agents deal with it, create issues to be dealt with later, or document that it's the expected behavior.

See the README at the repo root for how to load it, and [CONTRACT.md](CONTRACT.md) for what a project provides.
